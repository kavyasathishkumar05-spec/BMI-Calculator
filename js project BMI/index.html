What is BMI?

BMI stands for Body Mass Index. It is a value calculated using a person's weight and height. For adults, it can be used as a screening measure to understand weight categories.

BMI Formula

BMI = Weight (kg) / Height (m)²

BMI is a screening measure, not a medical diagnosis. It does not measure health on its own.
